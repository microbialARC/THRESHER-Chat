# Example questions

Use these to get started with THRESHER-Chat, in the [web interface](../web_interface.md) or the
[terminal chat](../usage_chat.md). They follow the four topics in the welcome message.

THRESHER-Chat explains THRESHER; it doesn't run it. Questions like *"Cluster my genomes"* will get an explanation
of how to do that with THRESHER, not results.

## Getting started

- What is THRESHER, and what problem does it solve?
- How do I install THRESHER?
- What are the system requirements for running THRESHER?
- Which THRESHER mode should I use for my first analysis?
- What is the difference between Full Pipeline and New Full?

## Understanding the science

- What is a phylothreshold, and why does THRESHER use it instead of a fixed SNP cutoff?
- How does phylogenetic correction work?
- What does CladeBreaker do, and when should I turn it off?
- What are the endpoint methods, and how do I choose one?
- What is the difference between a strain, a clone, a singleton, and a transmission cluster in THRESHER?
- How are the study, group, and public SNP matrices used?

## Running THRESHER

- What input files does Full Pipeline need?
- How should my metadata file be formatted?
- I have 5 new genomes to add to a completed run. Should I use New SNPs or New Full?
- How do I rebuild transmission clusters with a different endpoint method?
- What are the main stages of the pipeline, and what happens in each?

## Interpreting results

- Which output files contain the transmission clusters?
- How do I read the strain composition results?
- What can and can't THRESHER results tell me about transmission direction?
- How should infection prevention teams use THRESHER transmission clusters?

## Asking about your own files

Upload a file with 📎 first (see [uploading files](../web_interface.md#uploading-files)), then ask:

- Is this metadata file in the right format for THRESHER?
- What does this error in my THRESHER log mean?
- What do the columns in this THRESHER output table mean?

## Out of scope

THRESHER-Chat declines questions that aren't about THRESHER, for example:

- How do I assemble raw reads with SPAdes?
- What is the best antibiotic for MRSA?
